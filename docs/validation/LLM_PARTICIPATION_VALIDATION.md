# 模型参与度验收（2026-10-29）

为了直接判断本地模型实际起了多大作用，新增纯函数 `ai.participation`，模型页新增三行：

- **模型选定的长期筹划**：当前进行中、由模型选定的长期筹划数，以及累计选定、继续的次数；
- **与你来往的人中由模型主导**：与玩家来往过的人里，当前计划出自模型，或模型写的生活方针仍然有效的人数；
- **人物回应**：已完成的人物回应次数。

这几项加上原有的「模型计划实际执行」和「方针参与行动」，可以直接看出模型对世界走向和玩家当面体验各起了多大作用。统计只读，不改变存档。

另修正一处：模型工作线程原本假定每个任务都有 `self` 字段，没有该字段的任务会让线程退出，之后所有模型任务都停住；现在可以安全处理。

本 PR 起初还包含「江湖传闻」（大事由近及远传开、本地人转述），试用后判断用处不大，已整体删除。

## 验证

- `python -X utf8 -m unittest discover -s tests -q` 643 项通过，其中新增 `tests/test_participation.py` 2 项：统计各项计数，且查询不改变存档；没有 `self` 字段的任务不会让工作线程退出。
- C# 只做了括号配平检查。
