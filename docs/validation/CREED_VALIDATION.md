# 人生信条验收（2026-10-29）

本地模型想不过来每个人每周的选择，但可以替每个人写下他是什么样的人。规则在新模块 `jianghu/creed.py`：**模型写剧本，规则照着演**。

## 信条的内容

| 项 | 可选 | 规则怎么用 |
| --- | --- | --- |
| 信条 `motto` | 十六字内的一句话 | 显示用，并在之后每次思考时提醒模型 |
| 看重 `values` | 亲情、友情、情爱、公道、武道、财富、名望、自在、安稳、门派、家国，按轻重选两三样 | 每样会推动相应的行动：如「自在」推远行、少尽责，「安稳」多休养、少远行和比武，「公道」推报官。权重按排位依次为 1、0.6、0.3 |
| 底线 `bottom_line` | 不负亲人、不欺弱小、不背弃朋友、不违王法、不辱师门、无所顾忌 | 偷窃、勒索、造谣、背信、侵吞时大幅减分：不负亲人对亲人 −60，不背弃朋友对情分 20 以上的人 −50，不欺弱小对家资比自己少的人 −40，不违王法一律 −25，不辱师门（在门派中时）−15 |
| 受辱时 `when_wronged` | 隐忍、讨回公道、以牙还牙、一笑置之 | 比武 +12 至 −15，报官 +12 至 −5；复仇之心每月的消退：以牙还牙更慢，一笑置之更快 |
| 见利时 `temptation` | 不为所动、量力而取、见利忘义 | 不义之举 −20 / 0 / +6（背信、侵吞 +12） |
| 此生想要 `dream` | 六种人生心愿之一 | 重新选心愿时，这一项多加 10 分，随机抽签本身不变 |
| 倾向 `leanings` | 至多三类日常行动，各 ±6 或 ±12 | 直接加进每周的行动评分 |

信条写好后，此人以后每一次行动选择都会按它加减分，不再需要调用模型。**没有信条的人一律不加减**，行为与以前完全相同，已经调好的社会数值不受影响。

## 什么时候写

- **第一次被模型想到时**：无论走简短请求还是完整请求，只要此人还没有模型写的信条，回答里就必须带上信条（`creed_due`）。简短请求的输出上限因此临时多加 110 个 token。
- **人生转折时**：思考转折的回答也必须带上信条，可以照旧也可以改写。
- **满三年后复核**：信条写成 36 个月后会再次要求填写。旧信条记入履历。
- 已有信条的人，之后的思考资料里都会附上信条，提示要求取舍合乎信条。

信条在改动任何状态之前校验：全部字段齐全、选项都在范围内、看重的项和倾向不重复、信条句不含数字和系统字样。不合格时整份提案被拒，存档不变。

## 界面

- NPC「品性」页新增「人生信条」。例如：信条「宁折不弯」；看重公道、亲情；底线：不欺弱小；受辱时讨回公道；见利时不为所动；此生想要名动一方；不愿赌局。下方注明由本地模型写于第几月。还没有信条的人显示「尚未成形」。
- 模型页新增「已写人生信条的人物」。

## 规模估计

一个人的信条只在第一次被想到、人生转折和每三年复核时写，日常照着演，不耗模型。按上一项（#25）的简短请求和转折点优先，背景人物也会在思考中逐步写好信条。全体成年人多久能写完，取决于本机的实际速度。

## 验证

- `python -X utf8 -m unittest discover -s tests -q`：668 项通过，其中新增 `tests/test_creed.py` 7 项。覆盖：
  - 只接受格式正确的信条；
  - 没有信条的人不受任何影响；
  - 底线与见利态度改变作恶的倾向，能区分亲人、穷人和富人；
  - 看重和倾向推动日常选择，并确实计入引擎的每周评分；
  - 受辱时的态度改变比武倾向和复仇之心的消退；
  - 重选心愿时，此生所想多加分，随机抽签不变；
  - 第一次思考时写信条，不合格则整份拒绝；写好后附在之后的资料里，三年后复核，旧信条记入履历。
- `tests/test_lean_thinking.py` 中的 schema 与输出上限断言，改为包含信条。
- 试验：600 人世界推演 12 个月，给全部成年人随机写信条（信义低的人多选无所顾忌或见利忘义），与不写信条对照：
  - 犯罪 906 → 556；比武 60 → 50；远行 548 → 634；
  - 贫困率 6.6% → 6.2%，达成心愿 212 → 232；
  - 没有非法行动。

  随机信条大多带底线，所以犯罪下降。真实信条由模型按各人性格写，分布会不同。
- 这里没有显卡和本地模型，真实信条的质量仍需在本机验收。C# 只做了括号配平检查。
