# 门派九品武学功法设计

一品最高，九品入门。8个门派各9门，共72门。功法提供被动属性加成，实际兵器由装备决定。

身份传承部分按当前身份计算：门派人士掌握本派本品及以下品阶（例如五品对应五至九品），晋降品、离派和转派时重算这一部分。非门派人士按固定籍贯，以出身地区的门派为来源门派（每个地区一个门派），取得该派与当前社会品阶相同的一门身份传承；旅行和读档不重抽。

秘籍习得另行保存在人物的 `martial.learned` 中，使用一册对应秘籍即可永久学习。身份或门派改变不会删除这部分；它与当前身份传承取并集，同一功法只计一次加成。玩家从人物交互「修习 → 请教」取得秘籍后，仍需在自己的行囊使用。NPC 的求师、已有未学秘籍和冷却按当前规则处理。

旧存档缺少籍贯时，用最早记录的到访地点登记；无该记录则用当前所在地。主角采用创建时选择的出身地。随机来源使用独立种子，不消耗世界随机数。

加成直接累加至十项人物战斗能力，每项最高100；界面分别显示基础值、功法加成和实际值。品阶判定继续使用基础能力，避免功法加成反过来自动抬升品阶。

同品总加成：九品2、八品3、七品4、六品5、五品6、四品8、三品10、二品13、一品16。各门功法只提高列出的2至3项能力。

正道门派彼此和睦，邪道门派之间只是互不相犯，正邪之间先天嫌隙；丐帮中立偏正。下列宿敌在此之上再记一层恩怨：

- 宿敌 · 少林寺与明教：佛门正统与“吃菜事魔”的明教势同水火
- 宿敌 · 峨眉派与五毒教：川滇相邻，峨眉与五毒教争夺西南
- 宿敌 · 华山派与西域密宗：关中是挡在河西密宗东进路上的门户
- 争雄 · 少林寺与武当派：同为正道泰斗，暗中争夺武林盟主之位

两派往来低于-20（正邪之间开局即是如此）时，门中会发布「除魔」（正道）、「立威」（邪道）或「了断」（中立）差事，目标是对方门人，以真实交手定胜负；交恶门派的门人在同城相遇，也可能自行寻仇。
