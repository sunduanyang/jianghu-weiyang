# 皮影人物 · GPT 出图提示词（全身差分，截取头像）

用途：替换现在 8 张共用的静态头像（`static/assets/portraits.png`），让每类 NPC 有自己的皮影形象。
做法：**每个人物先出一张全身立像，再在这张图的基础上只改表情，做出差分**。头像从全身图里按固定位置截取，全身图本身留作立绘和拆件参考。

---

## 一、出图前先做的三件事

1. **每次都上传风格参考图。** 把已经定稿的「行路侠客」拆解图（或三人拆解图）一起发给 GPT，说「严格沿用参考图的皮影风格、配色和线条粗细」。只靠文字描述，几轮之后风格一定会漂。
2. **一张图只画一个人。** 不要让 GPT 一次画好几个人，也不要在同一张图里画几种表情。
3. **先跑 4 个人物试试，再铺量。** 第四节的第 1～4 号先画出来，确认构图位置、配色都对，再批量画剩下的。

---

## 二、构图规格（所有图都一样，截头像全靠它）

- 画布 **1024 × 1536，竖向**；
- 人物**站立静止**，纯侧面朝右，双臂自然下垂，双脚并立；
- **脚底**落在距画面底边约 90 像素的位置；
- **头顶**（不含冠饰）在距画面顶边约 190 像素的位置，冠饰最高不超过距顶边 80 像素；
- 下巴到头顶约 180 像素高，脖子正中大约在画面水平中线（x≈512）、距顶边约 400 像素处；
- 人物水平居中。

这样每张图的头都落在同一个区域，截头像时用固定框裁就行：**以 (512, 300) 为中心，裁 360 × 360**，包含头、冠饰和一点肩领。

---

## 三、通用风格段（每次都原样贴在最前面）

```
中国传统皮影戏人物，平面牛皮雕刻质感，半透明染色皮革，由平面零件和铜铆钉连接而成，
造型逻辑与上传的参考图一致：头茬、上身、双臂、前后裙片、双腿分件，关节处有铆钉。
严格纯侧面（90度侧脸），面朝画面右侧，只露一只眼一只耳。
人物站立静止：双臂自然下垂，双脚并立，身体挺直，不做动作。
配色只用：皮色 #E3C08A，墨黑 #1E1712，藏青 #2E3A55，赭黄 #C8962E，朱红 #A8322A，铜色 #9A6B34；白发用 #D8D2C4。
脸部保持素净：轮廓线清楚，眉眼用细线刻出，眼眶有一道墨色眼线，不画写实明暗。
镂空纹样只出现在冠饰、衣领、袖口和衣摆上，脸、脖子、手不镂空；全身只有一处纹样最精细（衣领或冠饰）。
平涂色块加细墨线，不要渐变、不要写实光影、不要做旧脏纹理、不要颗粒噪点。
背景：完全透明（PNG）。如果做不到透明，就用纯色平涂 #F3E9D2，不要任何纹理、阴影、地面线或边框。
画面里不要任何文字、印章、签名、水印，不要武器以外的道具漂浮在空中。

构图：画布 1024×1536 竖向，人物水平居中；脚底距画面底边约 90 像素；
头顶（不含冠饰）距顶边约 190 像素，冠饰最高不超过距顶边 80 像素；下巴到头顶约 180 像素高。
```

## 五、第二步：表情差分（怒、悲）

把第一步通过检查的那张图**上传回去**，然后分两次发下面的话，各出一张：

```
基于这张图修改：只改脸上的表情，其余所有地方保持完全不变——
发型、冠饰、衣服、颜色、姿势、人物大小和在画面中的位置一律不动，背景也不变。
表情改为：{表情}
```

| 差分 | `{表情}` 填写 | 文件名后缀 |
|---|---|---|
| 怒 | 发怒：眉头下压成倒八字，眼睛瞪圆，嘴紧抿或微张，下巴微抬 | `-angry` |
| 悲 | 悲伤：眉头上挑成八字，眼睛半闭下垂，眼角有一滴泪的刻痕，嘴角下垂，头微低 | `-sad` |

平静的底图文件名后缀用 `-calm`，例如 `m-escort-calm.png`、`m-escort-angry.png`、`m-escort-sad.png`。

> 以后想加别的差分（比如落魄版：衣服打补丁、颜色褪旧；受伤版：缠绷带），也用同样的「基于这张图修改，只改……其余完全不变」的说法。

## 六、拿到图以后怎么检查

满足下面全部条件才收下，否则重画：

- [ ] 纯侧面，面朝右，只有一只眼睛；
- [ ] 站姿静止，头顶和脚底的位置符合第二节的规格（可以用截图工具量一下）；
- [ ] 表情差分和底图相比，**除了脸以外完全一样**（两张图来回切换，身上不能有任何跳动）；
- [ ] 背景透明，或者是没有任何纹理的纯色；
- [ ] 只用了规定的几种颜色，没有渐变和脏纹理；
- [ ] 没有多余的手、文字、边框、印章。

常见问题和补救的话术：

| 问题 | 追加一句 |
|---|---|
| 画成了四分之三侧脸 | 「必须是严格 90 度纯侧面，像剪影一样只看到一只眼睛。」 |
| 人物太大或太小、位置偏了 | 「人物缩放到：脚底距底边 90 像素，头顶距顶边 190 像素，水平居中。」 |
| 差分时衣服或姿势也变了 | 「只允许改眉、眼、嘴，其余每个像素都保持原样。」可以多试两次，挑变化最小的一张。 |
| 太写实、有光影 | 「去掉所有明暗和渐变，只用平涂色块和细墨线，像真正的皮影。」 |
| 纹样太满太花 | 「脸、脖子、手不要任何镂空，镂空只留在冠饰、衣领和衣摆上，数量减少一半。」 |
| 所有人一个身材 | 在人物描述里把体型写得更具体，比如「肩宽只有成人男子的八成」「腰粗、肚子微凸」。 |
| 风格和参考图不一致 | 重新上传参考图，并说「线条粗细、配色、铆钉样式与参考图完全一致」。 |

## 七、图交回来之后

把通过检查的图按上面的文件名存进 `prototypes/shadow-puppets/figures/`。之后用一段脚本处理：
去背景 → 按第二节的固定框截出头像（360×360，缩到游戏需要的尺寸）→ 放进 Unity 资源目录，
替换名册和人物档案里现在的静态头像。全身图同时保留，作为立绘和以后拆件的参考。

游戏挑选形象的规则（实现时用）：

- **先看身份**：道士、僧人、官员、丐帮、门派弟子有专属形象；
- **再看营生**：农人、行商、药师、匠人、镖师、渔人、猎户、书生、艺人；
- **最后按性别和年龄段**兜底：童 <16、青 16–34、中 35–59、老 ≥60；
- 同一类形象有多张时，按人物编号固定挑一张，保证同一个人每次看到的都一样；
- **表情**：平时用平静；人物档案里，按当前情绪最强的一项切换成怒或悲；
- **以后的扩展**：同一类形象准备「落魄」「受伤」差分，按家境和伤病切换。
