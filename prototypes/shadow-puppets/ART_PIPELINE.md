# 美型皮影 · 拆件美术管线

目标：**人不变，衣服可换；脸由玩家搭配。**
每个人物 = 一具固定身体（人台）＋ 一套衣服（含头饰）＋ 一组头部零件（脸型 · 眼 · 眉 · 嘴 · 整头头发）。
所有零件都按同一副骨架（`unity/paper-rig.json`）画、切、拼，所以任意组合都能对上关节，也能直接进 Unity 的皮影运行时。

```
人物外观 = 身体(female / male)
         + 套装(outfit)：16 片身体衣片 + 独立配件 + 头饰(headwear，跟套装走)
         + 头部：脸型 face × 眼 eyes × 眉 brows × 嘴 mouth × 发型 hair（玩家/NPC 自由组合）
         + 染色：肤色、发色（引擎染，不另画）
```

以默认规模算：6 种脸型 × 8 种眼 × 8 种眉 × 4 种嘴 × N 种发型，相当于 1536·N 张脸。
要画的只有：1 张脸型图、1 张眼图、1 张眉图、1 张嘴图，每个发型 1 张图，每套衣服 2 张图（衣片＋头饰）。

## 1. 模板（已生成，在 `templates/`）

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `<body>/body.png` | 1024×1536 | 人台：纯侧面朝右，用来先画一张"穿好的整身设计图" |
| `<body>/outfit-sheet.png` | 1024×1536 | 套装拆件纸样：4×4 格放 16 片衣片，最下一行放配件 |
| `<body>/headwear-sheet.png` | 1024×1024 | 头饰：冠、簪、帽、巾、抹额 |
| `<body>/face-sheet.png` | 1536×1024 | 6 种脸型（含脖子、耳朵） |
| `<body>/eyes-sheet.png` | 1536×1024 | 8 种眼 × 平静/怒/悲 |
| `<body>/brows-sheet.png` | 1536×1024 | 8 种眉 × 平静/怒/悲 |
| `<body>/mouth-sheet.png` | 1536×1024 | 4 种嘴 × 平静/怒/悲（下半张空着） |
| `<body>/hair-sheet.png` | 1536×1024 | 左：常规发型；右：压发版（戴帽巾时用） |
| `spec.json` | — | 每一格的位置、比例、关节/锚点像素坐标（切图和拼装用） |

**洋红圈 = 这片零件绕着转的关节；青色点 = 下一个关节或头部锚点。**
模板上的灰色形状只表示位置和大小，成图时**全部换成真正的画**，记号、虚线和文字都不要留（留了也会被切图脚本去掉，但会脏边）。

身材比例：女 ≈ 7.9 头身，男 ≈ 7.7 头身，四肢长度沿用现有骨架，所以美型主要来自"小头＋修长"。

重新生成模板：`python prototypes/shadow-puppets/pipeline/make_templates.py`

## 2. 工作流

1. **定装（整身设计）**：把 `body.png` 和参考图一起发给出图模型，用下面的「整身设计」提示词，先得到一张穿好衣服的侧身全身像，确定配色和纹样。不满意就只改这一步。
2. **拆衣片**：把整身设计图 + `outfit-sheet.png` 一起发过去，用「套装拆件」提示词，得到 16 片衣片。
3. **头饰**：整身设计图 + `headwear-sheet.png`，用「头饰」提示词。冠、簪类叫 *crown*；帽、巾这类会压住头发的叫 *hat*（切图时加 `--hat`）。
4. **脸库 / 发型库**：这部分不跟着衣服走，一次画好，所有人物共用。
5. **切图**：
   ```bash
   cd prototypes/shadow-puppets/pipeline
   python cut_sheet.py ~/Downloads/qing-outfit.png   --body female --kind outfit   --id hanfu-qing
   python cut_sheet.py ~/Downloads/qing-headwear.png --body female --kind headwear --id hanfu-qing --hat
   python cut_sheet.py ~/Downloads/faces.png  --body female --kind face  --id set1
   python cut_sheet.py ~/Downloads/eyes.png   --body female --kind eyes  --id set1
   python cut_sheet.py ~/Downloads/brows.png  --body female --kind brows --id set1
   python cut_sheet.py ~/Downloads/mouth.png  --body female --kind mouth --id set1
   python cut_sheet.py ~/Downloads/bun.png    --body female --kind hair  --id high-bun
   ```
   结果在 `library/<body>/<kind>/<id>/`（PNG + `manifest.json`）。有 ⚠ 提示就看一眼：多半是画出了格子，或者某格是空的。
6. **拼装检查**（换装、捏脸、表情、摆姿势）：
   ```bash
   python assemble.py --body female --outfit hanfu-qing --headwear hanfu-qing \
     --face set1:3 --eyes set1:2:angry --brows set1:5:angry --mouth set1:1 --hair high-bun \
     --skin "#f1d9c4" --hair-color "#2b2230" --pose '{"near_upper": -60, "near_elbow": -30}' --out check.png
   ```
7. **进游戏**：`python bake_library.py --body female --id npc-qing ...（同上参数）` 会输出图集和皮肤 JSON，格式与 `Resources/PaperCast/index.json` 里的皮肤完全一致；现有 `PaperCast.cs` 不用改就能画（头部每一层都是挂在 `neck` 上的零件）。
8. **自检**：`python selftest.py` 会用假图跑一遍"画→切→拼→烘焙"，并核对烘焙结果按运行时规则画出来和拼装预览一致。

## 3. 出图规则（给自己，也写进提示词）

- **美型优先**：小头、长颈、窄肩（女）/宽肩窄腰（男）、长腿，五官精致；不要传统皮影的大头、夸张五官。
- **皮影的材质，不要皮影的缺点**：半透明染色皮革、镂刻纹样、透光感、民间装饰（缠枝、云纹、回纹、如意、团花）；**不画签子、不画铜钉/铜环**。关节靠零件**互相压住**来遮挡：每片肢体顶端画成圆头，被上一片盖住。
- **抠图要真透明**：背景必须是纯透明，或者一整片平整的浅色纸色（脚本会抠掉）。透光感是游戏里用光照做的，PNG 本身不要做半透明。
- **零件不出格、互不粘连**：每片画在自己的格子里，留一点空。袖口、手肘的布料画在**前臂片**上；裙摆、衣摆画在**前后裙片**上；腰带、玉佩画在**腰饰片**上。
- **肤色、发色画成中性灰**（脸、脖子、手用暖灰，头发用中灰带明暗），游戏里染色；眼睛的黑眼珠、唇色可以直接画颜色。
- **不要高跟、不要过多飘带**：飘带只能从固定的点（腰、袖口、冠）垂下来，不跨越两片零件。
- **每个人物一个主题色 + 一个纹样**，方便一眼认出，也方便同一套衣服换色出 NPC。
- **全部纯侧面朝右**，和人台一致；脸型、发型、头饰都按头部模板的位置画，不要自己挪。

## 4. 提示词

> 用法：每次都把**对应模板图**作为参考图上传，再贴「通用风格」+「这一张的提示词」。
> 写明"保持参考图的画布尺寸、格子位置和每个零件的位置与大小不变"。

### 4.1 通用风格（每次都带上）

```
风格：精致美型的中国皮影戏人物，纯侧面朝右。人物比例修长（约 7.5–8 头身），小头长颈，五官秀美，
现代审美的美型，而不是传统皮影的大头和夸张五官。
材质：半透明的染色牛皮，镂空雕刻纹样，像背后有灯光透过的效果；民间美术的繁复装饰——缠枝花、云纹、
回纹、如意纹、团花，线条细密精致；配色用矿物色（石青、朱砂、藤黄、胭脂、墨），有手工染色的深浅。
禁止：不要画操纵签子、不要铜钉铜环、不要关节圆点；不要背景、不要阴影、不要文字和记号；
不要高跟鞋；飘带少而短。
输出：透明背景 PNG（如果做不到，就用一整片平整的米白纸色背景，不要纹理）。
```

### 4.2 整身设计（定装）

```
参考图是一具人台（成年女子/男子，纯侧面朝右，静立）。请给这具人台穿上：
【角色：例如 青衫女侠，主题色石青，纹样卷草；交领短襦、束腰、长裙，护腕，软靴；发髻上一支银簪】
要求：完全沿用人台的姿势、比例和头的大小与位置，只画衣服、鞋、头饰和配件；
脸部画成中性暖灰色的美型侧脸（以后会替换），头发画成中灰色。
```

### 4.3 套装拆件

```
参考图1是这套衣服的整身设计；参考图2是拆件纸样（4×4 格加一行配件）。
请把这套衣服拆成独立的皮影零件，逐格画在纸样对应的格子里：每格一片，零件的长度、方向、
关节位置（洋红圈）和下一关节位置（青色点）与纸样里的灰色形状一致，宽度可以按衣服加宽。
每片肢体顶端画成圆头，用来在关节处被上一片压住（关节隐藏在重叠里，不画钉子）。
袖子、袖口画在前臂片上；裙摆画在前裙片、后裙片上；腰带、玉佩、流苏画在腰饰片上；
手和脚画成中性暖灰色（鞋子画颜色）。兵器、背篓等配件横放在最下一行，每件完整、互不重叠。
不要画脸和头。去掉纸样里所有的灰色形状、圈、点、虚线和文字。
```

### 4.4 头饰

```
参考图1是整身设计；参考图2是头饰模板（灰色头像只表示位置）。
请只画这套衣服的头饰【例如：银簪＋小发冠 / 斗笠 / 幞头 / 抹额】，位置和大小对准模板里的头和发髻虚线圈，
冠和簪落在头顶"冠"点附近，抹额沿"额"点。不要画头发、脸和灰色头像。透明背景。
```

### 4.5 脸型（6 种）

```
参考图是 6 格脸型模板（纯侧面朝右，含耳朵和脖子）。请在每格画一种美型侧脸轮廓：
1 鹅蛋 2 瓜子 3 圆润少年 4 清瘦 5 方颌英气 6 长脸成熟。
只画皮肤（中性暖灰）、耳朵、脖子、鼻子和下巴轮廓的细线，以及皮影式的镂刻细纹；
不要画眼睛、眉毛、嘴和头发。眉、眼、嘴、耳、冠、颈的位置必须和模板里的点一致，
脖子底部对准洋红"颈"点，头的大小不要变。
```

### 4.6 眼睛（8 种 × 3 表情）

```
参考图是眼睛模板：每格中心的青色十字是眼睛的位置，浅灰色是脸的局部（只作参考）。
每一行三格是同一种眼型的 平静 / 怒 / 悲。8 种眼型：
1 丹凤 2 杏眼 3 桃花 4 柳叶细长 5 圆眼 6 下垂眼 7 吊梢 8 老成（带眼袋纹）。
每格只画一只侧面的眼睛（眼眶线、睫毛、眼白、黑眼珠），眼睛中心对准十字，大小保持一致；
皮影刻线风格，精致美型。不要画皮肤、脸和眉毛，去掉浅灰色脸。透明背景。
```

### 4.7 眉毛（8 种 × 3 表情）

```
参考图是眉毛模板，规则同眼睛。8 种眉形：
1 远山眉 2 柳叶眉 3 剑眉 4 平直眉 5 新月眉 6 短粗眉 7 八字眉 8 浓眉。
每格只画一道侧面眉毛，颜色用中灰（会染成发色），中心对准十字。怒＝眉头压低，悲＝眉头上扬。
```

### 4.8 嘴（4 种 × 3 表情）

```
参考图是嘴模板（只用上面两行，共 12 格）。4 种嘴型：1 樱桃小口 2 薄唇 3 丰唇 4 宽口。
每格只画侧面的唇（含唇色），中心对准十字；怒＝紧抿下撇，悲＝嘴角下垂微张。
```

### 4.9 发型（每种一张）

```
参考图是发型模板：左格画常规发型，右格画同一发型的"压发版"（戴帽子、头巾时用：发顶压平，
只留鬓角、后脑和垂下的发尾）。发型：【例如 高髻＋两缕鬓发＋长发垂至腰】。
头发整头画成一片（含刘海、鬓角、发髻、垂发），颜色用中灰带明暗和发丝刻线（会染色）；
贴合模板里的头形，头顶对准"冠"点，耳朵前的鬓角不要盖住眼睛。不要画脸和灰色头像。透明背景。
```

## 5. 验收清单

- [ ] `cut_sheet.py` 没有 ⚠（或已确认无碍）。
- [ ] 拼装图里：关节处看不到缝，也看不到圆头露出来；手臂抬到 -70°、腿迈开 30° 时仍然连贯。
- [ ] 换 3 种脸型、3 种发型都不穿帮；戴帽子时自动用压发版。
- [ ] 怒/悲表情的眉、眼、嘴位置不跳。
- [ ] 肤色、发色各试一深一浅，染色后明暗还在。
- [ ] 透明边干净：在深色和浅色背景上都没有白边/黑边。

## 6. 运行时（下一步）

- `bake_library.py` 的输出已能被现有 `PaperCast.cs` 画出来；还需要：
  1. 把烘焙出的皮肤合并进 `Resources/PaperCast/index.json`（或让运行时额外读一份 library 索引）；
  2. 表情切换：皮肤里的 `expressions`（`head-eyes@angry` 等）替换同名的 `head-eyes`/`head-brows`/`head-mouth`；
  3. 肤色/发色改成运行时染色（现在是烘焙时染好），这样同一套资源能生成更多 NPC；
  4. NPC 存档里只记外观选择：`{body, outfit, palette, face, eyes, brows, mouth, hair, skin, hair_color}`。
