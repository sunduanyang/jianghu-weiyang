# 纸上争锋 · 物理格斗 Demo 0.9

参考《Bloody Bastards》的双手操作与物理战斗思路，使用《江湖未央》现有分件人物制作的独立 Unity Windows 试玩。人物、界面和代码属于本项目，不包含原游戏素材或代码。

## 运行

双击项目根目录的 `启动物理格斗Demo.bat`，或直接运行 `Build-v09/纸上争锋.exe`。成品不需要安装 Unity、Python 或联网。整个 `Build-v09/` 文件夹需要一起保留。

- **W / 兵器按钮**：为双方分别选择兵器，确认装备后重新开局。首页、交战和暂停时均可打开；取消保留当前对局。
- **进入擂台**：与会进退、挥剑和架盾的 AI 对战。
- **自由练习**：陪练不主动攻击，保持防守，适合练习绕盾和控制剑尖。
- **A / D、左右方向键**：移动。
- **浮动轮盘**：平时隐藏。在擂台内按住鼠标左键控制主手兵器，按住右键控制副手（单手款控盾，双手款牵引副手）；轮盘以按下点为中心出现，拖动方向决定转臂方向，拖远伸展，绕盘整圈转臂。底盘始终固定在本次按下点，滑块超出半径时停在圆盘边缘；松开隐藏并回守势，下次按下在新位置生成。鼠标按键决定手臂，与按下位置左右无关。
- **触屏**：在左半屏按下控制副手，右半屏按下控制主手，两个指针分别捕获；跨过屏幕中线不会换手。中心死区内保持守势，拖到外圈可伸直上举。
- **屏幕下方 ← / → / 进身**：按住移步或点击向前进身，方便触屏试玩。
- **鼠标相对拖动**：方向按相对轮盘中心的位移计算；按下时不会因鼠标离人物较远而立刻拉直手臂。也可按 K 防守，单手款架盾、双手款架杆。
- **J**：依次使出直刺、挑斩与劈斩，按住可连续变招；**L**：直刺；**K**：防守，单手架盾、双手架杆，适合纯键盘试玩。
- **气力与恢复**：手动和按键攻击起手按兵器消耗 5～18 点气力，兵器持续挥动另有运动消耗，连续快速甩动会增加负担；气力不足不能开始新攻击，低气力的手臂转速和发力会下降。受击中断攻击；攻击、进身或格挡后延迟回气，持盾或双手架杆时回气较慢。顶部显示气竭、卸力和恢复状态。
- **S / 下方向键**：沉身；**Space**：消耗气力向前进身。
- **R**：重新开局；**Esc**：暂停、切换模式、返回首页。
- **H**：操作说明；**M**：声音；**V**：叠加实际碰撞轮廓、骨骼与落脚目标（绿：支撑；橙：等待落地；蓝：抬脚）。

每次运行从首页开始，窗口失去焦点会暂停。试玩没有世界存档，也不连接正式游戏的规则进程。

## 兵器

| 兵器 | 每次攻击气力 | 特点 |
| --- | --- | --- |
| 匕首 | 5 | 极短，轻快，单次伤害较轻 |
| 短刀 | 7 | 中短距离，挥动较快 |
| 单手剑 | 9 | 单手配盾，原有均衡兵器 |
| 单手斧 | 12 | 斧头劈击强，压盾较重 |
| 钉头锤 | 14 | 锤头冲击与压盾强，挥动较慢 |
| 长枪 | 11 | 双手分握长杆，枪头远刺，枪杆无伤 |
| 双手大剑 | 13 | 双手握持长柄，挥斩有力，不配盾 |
| 双手战斧 | 17 | 双手分担重斧，重劈和压杆 |
| 双手战锤 | 18 | 双手重击，冲击强，回收较慢 |

武器外形与伤害碰撞体使用同一份几何定义。握柄、枪杆和护手参与实体碰撞，但不扣血。武器质量、惯量、挥动速度、攻击间隔、气力消耗、伤害系数和压盾能力随兵器变化，AI 的交战距离也会调整。长枪、双手大剑、双手战斧和双手战锤占用双手，不创建盾牌模型或碰撞体。武器为独立刚体，两只手分别通过固定握持关节连接同一把武器的两个握点；双臂求解共同可达的目标姿态，再用有力上限的手腕软目标牵引身体。两个目标保持一致的握距，避免两手互相拉扯。正常状态保持握持，倒地时松开两手并停用目标牵引，武器自然落地。

## 双手兵器操作

左键控制主手挥砍、伸展与直刺；副手共同持械。右键二维拖动牵引副手，两手共同改变兵器位置与方向，K 进入双手架杆姿态。触屏左半屏控制副手、右半屏控制主手。轮盘底盘继续固定在按下点，松开隐藏。

双手动作受两臂可达范围约束。主手确定主要运械方向，副手的二维输入改变另一握点的意图，两手共同影响兵器的平移与转动；握距由兵器定义。长兵器下转时，握持姿态会避开地面；武器仍参与真实碰撞。V 可查看实际握持连接和碰撞轮廓。换回单手款会恢复木盾和独立盾手操作。

## 手部物理驱动

0.9 以手腕软目标承担主要牵引，目标作用在腕部铰链的前臂一侧，最大牵引力受气力、受击、兵器和架势限制。肩肘保留较弱的姿态辅助，单手腕保留有力矩上限的转向辅助；不会每帧直接设置手臂或武器的物理位置。双手款的两处目标共同引导独立兵器，遇到实体阻挡会偏转、停住或拉动身体。双手转向辅助有力矩上限，并向两条前臂施加等大反向合力矩；目标领先角受实际兵器姿态限制，避免重兵器尚未跟上时双手提前翻转。握持端增加有效转动惯量，避免细小手掌与长武器惯量差异导致约束难以收敛。

控制、握点、碰撞取样与气力计量统一使用 Rigidbody2D 当前物理姿态，不以插值后的画面姿态作为反馈。持续耗气按兵器相对躯干的运动计算，整个人物一起平移不会被当成挥砍。连挥会积累负担，停手后逐渐消退。原有起手付费、受击中断、零气力拒绝与局部遮挡规则继续使用。

## 实现范围

使用 Unity Physics2D 的独立骨盆、躯干、头部、双臂、双手和双腿刚体。肩关节允许 360° 转动，外圈使用接近全长的双骨骼 IK。0.5 将主动目标的肘部弯曲限制为最多 132°，实体关节保留到 150° 的受力余量；避免手腕目标落进肩旁的过度折叠区域。手臂伸缩有速度过渡，盾臂方向也平滑跟随。手腕限位按真实前臂相对角度和角色朝向校准，替代初始绑定姿势的对称限制。待机持剑手略向前伸、肘部下垂，减少横臂挤在胸前的姿态。铰链电机仍有速度和力矩上限，根部保留有阻尼的平衡辅助；受击减力后逐渐恢复。脚步分为抬脚、等待真实接地和支撑三个阶段。支撑脚使用有力上限的软约束，迈步、明显受击或倒地时释放，鞋底独立设置摩擦；不会直接移动物理脚掌的位置。步幅受限，身体不会持续跑出支撑范围；摆动腿跟随真实髋部，支撑腿同时跟随重心高度。脚跟、脚尖与接地高度按朝向和实际碰撞体校准。

浮动轮盘按指针编号分别捕获输入；暂停、失焦、重开和结束时释放全部指针，触屏取消或指针消失时也会清理。触屏产生的模拟鼠标不会抢走轮盘。血条、帮助按钮和屏幕底部不会生成手臂轮盘；移步按钮独立处理。鼠标仍是一个位置，单手款想独立控制剑盾可使用双指，或配合 K 防守；双手款的两臂共同跟随同一把武器。

武器使用独立刚体和主手握持关节，木盾仍与盾手构成复合刚体，手腕活动受限；身体使用分段胶囊与躯干多边形，剑刃、无伤护手和盾牌有各自的实际形状。命中使用接触点朝向内的法向速度与有效质量，正在离开身体的接触不补算伤害。同一物理步先结算格挡冲击，再沿各身体命中点的实际来向检查局部遮挡；取消碰盾后整把剑的全局伤害锁。盾面仍保护实际挡住的位置，同一步的盾边接触不自动保护露出的头腿。每次挥剑对同一人只扣一次血，延迟到达的碰撞保留原挥剑编号。持续压剑只消耗一次冲击气力；低气力遭重击后盾臂短暂卸力，盾牌仍参与碰撞。气血归零后关闭关节电机、手部软目标与两处握持约束，保留布娃娃倒地和兵器落地。

手动与按键攻击通过同一付费入口生成攻击编号和有效窗口，连续拖动达到足够转角、或回收后再次前伸时才请求新攻击；提交有最小间隔。受击取消原攻击，恢复时不会自动复活旧攻击。气力消耗后延迟恢复，格挡恢复更慢，AI 气力不足时后撤回气。接触回调保留当时的攻击状态，使同一物理步中实际同时命中的双方可以交换伤害。

肘部绘制在袖片下补齐皮肤连接，并在运行时裁去大臂袖片越过绑定肘点的多余尖角，不修改源图集。预设劈斩和挑斩由整臂走弧线带动武器，动作时长按关节转速调整，避免用固定手位要求手腕过度翻转。

开源阅读与具体借鉴点见 [REFERENCES.md](REFERENCES.md)。
这是验证操作和碰撞的原型，包含两个人物、九种兵器、单手款木盾和一处擂台。没有装备成长、联机、肢解或正式游戏战斗接入。

人物图集与绑定数据来自 `unity/JianghuUnity/Assets/Resources/PaperCast/` 中的青年农人男女两套素材；不绘制关节金属配件或操纵杆。字体为 Noto Serif SC，许可见 `Assets/Resources/Fonts/LICENSE-OFL.txt`。音效由程序合成。

## 开发与构建

用 Unity **6000.6.7f1** 打开本目录。首次运行 `DuelBuild.Build` 会创建 `Assets/Scenes/Duel.unity`，之后可直接在编辑器打开场景播放。菜单 **纸上争锋 → 构建 Windows Demo** 输出 `Build-v09/`。

也可以运行：

```powershell
& 'D:\Unity\Editors\6000.6.7f1\Editor\Unity.exe' -batchmode -nographics -quit -projectPath "$PWD\demos\PhysicsDuelUnity" -executeMethod DuelBuild.Build -logFile "$PWD\demos\PhysicsDuelUnity\build.log"
```

自动实机检查用 `-duelSmoke <绝对输出目录>` 启动成品，检查浮动轮盘、弯臂、伸直上举、双肩完整转圈、前后移步、实体接触、气力、九种兵器、四种双手握持、软目标受阻与受力上限，最后进行 AI 对战，输出截图与 JSON。附加 `-duelCheck grips -duelFps 30` 检查低帧率双手动作，附加 `-duelCheck spar` 检查四组正常气力和真实碰撞对战。机械活动范围检查隔离双方碰撞并补满气力；正常对战不补充气力。此模式运行后自动退出。指针测试通过与运行时相同的捕获接口注入，不代替真机触屏测试。具体结果与复现条件见 `VALIDATION.md`。
