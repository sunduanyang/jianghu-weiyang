# 界面手绘素材 · GPT 提示词

`bake_ui.py` 生成的界面贴图已经改成手作质感（毛边绢面板、漆木名牌、描金云头、远山底栏）。下面这些素材程序画不好，需要“画出来的东西”，交给 GPT 生成后放进 `Assets/Resources/UI/Art/`，**文件名照抄**，游戏会自动优先使用，不用改代码。没放的就继续用程序烘焙的版本。

## 通用风格段落（每条提示词前都完整粘贴）

```
风格：南宋工笔淡彩，像古籍插图和漆器描金纹样，用于一款武侠沙盒游戏的界面。
- 深墨色勾线，线条有毛笔的粗细起伏，不要矢量感的均匀细线。
- 色彩厚实但低饱和：墨绿 #1E2A28、石青 #3F6E6E、赭石 #9C7445、旧金 #C9A35A、朱砂 #B23A2A、宣纸色 #E6DCC6。
- 平涂加少量干笔皴擦，可以有纸纹和轻微磨损，不要渐变发光，不要金属反光，不要3D渲染。
- 物件造型简洁可辨认，像木刻版画一样清楚，缩小到64像素仍能认出。
- 不要文字，不要水印，不要边框。
```

## 1. 底栏和顶栏图标（最优先，效果最明显）

现在底栏是“圆圈里一个字”，换成画出来的小物件，“人味”会立刻出来。一次生成一整张，风格才统一，生成后切成单个 PNG。

```

一张游戏图标精灵图，4列×2行，共7个图标，均匀排列在纯色 #FF00FF 背景上，每个图标居中、互不重叠、四周留白。每个图标是一件画出来的小物件，旧金色勾边，主体用墨绿、赭石和朱砂：
1. 人物：一位戴斗笠的江湖人半身侧影
2. 行囊：系着绳结的布包袱
3. 功法：一卷半展开的竹简秘籍
4. 势力：一面插在石座上的三角令旗
5. 年谱：一本线装书和一支毛笔
6. 皮影：一个镂空的皮影人头像，带竹签
7. 推演：一个罗盘
所有图标同样大小、同样线条粗细、同样视角，没有背景圆圈。
```

## 4. 底栏远景（可选，替换程序画的远山）

GPT 不能直接出超宽图，先出横图，再裁成长条。

```
【风格段落】
一幅横向长卷的下边缘部分：近处是一道墨绿色的实心地面带，占画面下方三分之一，表面有极淡的云纹；地面带上方是层层叠叠的远山、松树和几处南宋屋檐的剪影，越远越淡，像水墨晕开的雾气；山顶以上是纯色 #FF00FF 背景。地面带正中向上微微拱起一道弧线，弧线下方要空着，用来放月盘。画面左右对称地延伸，没有任何人物。
```

裁剪：保留地面带和山，最高的山尖到画面顶，缩放为 2048×192，存为 `bottombar.png`。游戏把它拉伸铺在屏幕底部 154 像素高的区域，月盘压在正中。

## 5. 长卷设施建筑（城中「长卷」视图）

长卷里每处设施是一张单体建筑画，现在由 `bake_scroll.py` 用程序画。换成 GPT 画的版本后，放进 `Assets/Resources/Scroll/Art/`，游戏会优先使用；哪张不满意就删掉，程序画的版本会自动顶上。

**做法**：16 张都在同一个对话里生成。先出客栈，满意了再继续，后面每条都加一句「与前面几张同一画师、同一比例、同一线条粗细与设色」。不要一次要求多张拼在一起，否则比例会乱。

### 长卷通用段落（每条前完整粘贴）

```
风格：南宋界画，像《清明上河图》里的屋宇那样的工笔建筑画，用于武侠游戏的横向长卷街景。
- 画一座单体建筑的正立面，视点略高（约 10 度俯视），接近左右对称，不用近大远小的透视。
- 用界尺勾墨线：屋脊、檐口、柱子横平竖直，线条细而挺；瓦垄、斗拱、门窗交代清楚但不琐碎。
- 淡彩平涂，略带绢本晕染，低饱和：屋顶青灰 #4A5052，墙身米白 #E2D3AE，柱与门窗朱砂 #8E3122，木作赭石 #7A5636，点缀石绿 #56806F、花青 #3E5E70。没有高光、没有投影。
- 建筑立在一条看不见的水平地面线上，地面线在画面下缘往上约 8% 处，台基底边贴住这条线，线以下留空。
- 建筑左右居中；画面左上角（宽约 8%、高约 30%）什么都不要放，游戏会在那里挂名签。
- 不要人物、动物、车马；不要任何文字、匾额字、招牌字、印章、落款、边框；不要天空、远山、云雾、地面纹理和阴影。
- 不要 3D 渲染、照片写实、动漫上色、厚涂，不要明清式的繁复彩画，不要日式建筑特征。
- 背景是纯色 #FF00FF，横幅 3:2（1536×1024）。
```

### 放进游戏

```powershell
python unity/import_scroll_art.py --preview 长卷预览.png 下载目录/building_*.png
```

脚本会抠掉 #FF00FF、去掉品红边，把画面缩到 442 像素宽，并把建筑的脚落到长卷的街线上（舟埠保留自己的水面构图）。结果写进 `Assets/Resources/Scroll/Art/`，同时生成 `.meta`。`--preview` 会把导入的建筑排在绢底上并画出街线，脚没落在线上的一眼就能看出来。文件名必须是 `building_<类别>.png`，类别见上表。

**检查要点**：不要有文字或乱码字（GPT 常在匾和旗上写假字，提示词已要求留空，出了就重画）；屋檐线条是否横平竖直；颜色是否和前几张一致，偏艳的那张宁可不放。

## 处理方法

1. **去背景**：GPT 的透明背景不稳定，统一用 #FF00FF 品红背景，再用脚本或 Photoshop 的“色彩范围”抠掉，边缘收缩 1 像素去品红边。
2. **切图**：精灵图按格子切开，每个图标裁成正方形，四周保留约 10% 空白。
3. **统一调色**：放进去之前把所有图标映射到上面的色板，避免某一张偏艳。
4. **少即是多**：哪张画得不满意就别放，程序烘焙的版本会自动顶上，不会出现空图。

## 不需要交给 GPT 的部分

面板、按钮、名牌、列表行、输入框、顶栏都需要九宫格拉伸，GPT 画的整图拉伸后会变形，所以继续由 `bake_ui.py` 生成。想调它们的颜色或毛边程度，改 `bake_handmade()` 里的参数后运行 `python unity/bake_ui.py --ui-only`。
