# 试玩入口

双击项目根目录的 `试玩移植版BloodyBastards.bat`，先进入“出战配置”。

- 选择地区，再填写该地区的关卡编号（1–1000），也可以用 `+` / `−` 调整。
- 左侧选择主手、副手或防具部位，中间选择装备。支持英文名称或完整装备编号搜索，以及翻页。
- 选择双手武器会占用副手；选择单手武器后可再次调整副手。编号 0 表示未装备。
- 点击“保存并出战”会用这套装备重新开始所选关卡。“返回”会放弃这次尚未保存的修改。
- 战斗中按 `F2`，或点击右下角“装备 / 选关”，可重新打开配置。暂停菜单里的 `Loadout` 也可进入。
- “初始装备”只恢复装备搭配，保留当前选择的地区和关卡。已保存的配置会在重试和重新启动后保留。

当前是自由搭配的本地试玩配置入口；装备选择不扣金币。根据用户 2026-10-30 的选择，入口接续当前新窗口的存档：`output/bloody-full-port-20261028/held-control-27/native/progress.json`，装备配置在旁边的 `progress.json.setup.json`。这份存档是持续使用的玩家数据，请勿当作临时输出清理。之前的 `Build/BloodyBastardsPlaytestSave/progress.json` 及其装备配置也仍然保留。

战斗操作：`A` / `D` 行走，鼠标左键按住拖动控制主手，右键按住拖动控制副手，`空格` 踢击，`Esc` 暂停。鼠标按住时，虚拟摇杆底座固定在按下的位置。

松开鼠标后，手臂继续以最后的方向维持控制，效果等同继续按住。例如把副手盾顶在前方，松开鼠标后仍保持举盾。下一次按下并拖动会从上次位置继续调整，体力按原有持续控制规则消耗。暂停时停止控制，恢复后继续维持，重开战斗则从初始姿势开始。

试玩入口默认按显示器原生分辨率全屏启动。按 `F11` 可在无边框全屏与大窗口间切换，窗口也可拖动边框调整大小。
