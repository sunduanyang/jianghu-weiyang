# 江湖未央

本地运行的武侠社会沙盒原型。本分支已加入四周行程、灰度人格与更密集的 AI 评审。Python 3.12+，无第三方 Python 依赖；网页界面不依赖 CDN。已在本机 RTX 4060 Laptop 8 GB / 32 GB 内存上运行 Qwen3 4B Q4_K_M。

## 开始游玩

本任务的独立预览：双击 **预览丰富人生.bat**，打开 <http://127.0.0.1:8767>，使用本 worktree 的独立存档与配置。已有模型服务可直接共享；Git worktree 不复制被忽略的模型文件。

默认项目入口：双击 **启动江湖.bat**，打开 <http://127.0.0.1:8765>。也可在本目录运行：

```powershell
python run.py
```

首次创建 100 人世界并真实预演 18 年。界面提前可用，预演完成后暂停；以后重启续读存档。点人物或地图上的圆点查看人生；「此刻 / 心性 / 关系 / 年谱」分别展示目标计划、人格变化、关系与原始历史。点击事件查看客观结算及前因。

- 「一月 / 一年 / 十年」推进指定时间；「自行演化」持续运行；「暂停」保存。
- **规则快进明确跳过模型调用**，用于观察几十年演化。启用模型时关闭此选项，让重要决策进入共享推理队列。
- 可赠银、切磋、交谈，也可暂停世界，单独「请其反思」。人物的话语和玩家输入只作为经历，不作为引擎命令。
- 「另起江湖」支持 100 / 500 / 1000 人、种子与预演年数。每次新建使用独立数据库，旧世界保留。
- 「人间秩序」显示在世世代、出生、死亡、在孕家庭、县衙国库及真实任职者；「五十年」便于观察后代成长。人物关系页可追踪父母、子女、监护人与各代人物。
- 世界按月自动保存到 `data/`；`data/active_world.txt` 指向当前存档。恢复旧世界可用 `python run.py --db "绝对存档路径"`。程序会检测端口是否已有实例。

双击 **停止江湖.bat** 可保存并停止本项目默认端口上的游戏和模型，释放显存；手动启动时也可按 Ctrl+C。再次打开会继续上次人生。

## 本地 AI

本机已经准备好 `.runtime/` 下的模型与运行时。双击 **启动本地模型.bat**，然后在界面「本地模型」启用 AI。

从空拷贝准备模型：

```powershell
python scripts/setup_model.py
python scripts/start_model.py
```

下载约 2.4 GiB 模型及约 37 MB 的 llama.cpp Vulkan 包，均留在项目内，不安装系统服务。下载支持断点续传；来源、大小和 SHA-256 保存在 `.runtime/manifest.json`。模型服务只监听 `127.0.0.1:11435`，全世界共享一个推理槽。显存占用实测约 4.9 GB（含本机其他图形应用）；首次 Vulkan 预热较慢。

也支持已有的 Ollama：安装后运行 `ollama pull qwen3:4b`，选择 Ollama，地址 `http://127.0.0.1:11434`，名称 `qwen3:4b`。**Ollama 适配已实现，当前机器上的实测使用 llama.cpp。**没有模型时关闭 AI，完整规则模拟仍可运行；推理异常会显示错误并继续规则行动。

模型参与：选择合法行动、提交未来数周、可跨两个月续用的计划、在允许的时机调整长期目标、引用已知事件作主观解释并提出心理变化方向。JSON schema 限定候选；程序再验证当前前置条件、记忆归属、目标选项和提案时效。程序决定花费、接受、失败、受伤与实际心理变化。

默认每月评审 24 人（原为 2 人），常规冷却 3 个月（原为 6 个月）。按久未评审程度与真实事件紧迫性轮转，重要事件可提前触发；队列上限 48 人，所有人共享单个模型。每次请求只含一个人物，反思编号也限定为提供的记忆候选。世界推进到待决提案之后一个月时暂留时间预算，让计划在情境过期前落地。

规则逐周处理日常执行；AI 直接选择行动、排计划和解释经历。观测台分开显示调用数、已评审人数、近一年实际执行 AI 计划的人数、累计 AI 行动与预计每月推理时间。当前机器一人约数秒，每月 24 人约需 2～3 分钟；可以调整预算，1000 人仍共享此预算。推理账本保留完整输入、输出、耗时、tokens 和采纳/拒绝原因。

## 模拟规则

一个游戏月有四周时段。谋生、远行、决斗和勒索占两周，其他通常占一周；执行后依现实反馈选择下一项。合作也占伙伴的一周，同一机会不能无限刷取。工资、训练、休息效果按时段缩放，生活费每月只扣一次，避免活动增多导致收入凭空翻倍。

- 八项稳定倾向（包括诚实、贪欲、暴烈）、三项衰减情绪、三项世界信念、六项欲望分别存储。
- 目标有起点、原因、5～20 年愿景、可计算条件；规则通常至少持续四年才算完成，危机可导致转志。计划失效、生活拮据或伤重时重新安排。
- 行动还包括照料、消遣、静思、赌局、勒索、中伤与侵吞公帑。自利、护短、贪欲、仇怨、压力和孤独共同影响取舍；同一人可以帮助亲人也伤害别人。高值不等于更好，UI 展示性格两端。
- 犯罪实际转移财物；秘密行为不会泄露作案人，流言保留说话人及未核实标记。官员挪用会减少真实国库，审计可能曝光，报案后由县衙裁定赔偿、罚银与限期劳役；受罚会挤占可支配时间。心理变化区分施害者、受害者和办案人，作恶获利也可能逐步侵蚀诚实。
- 性格影响行为评分和事件解释；每次体验提出微量变化，按月限幅。重复经历可以缓慢积累，重大经历可提高变化上限。AI 只能提交方向，不能指定持久属性的数值。
- 每项客观事件只写一次，并为参与者建立索引；同一个事件可以形成不同的主观记忆。亲历和听闻有来源标记；未被发现的窃银不会告诉受害者作案人。人物工作记忆有限，但历史上的解释、实际心理变化及 AI 再解释版本全部追加保存，不因人物遗忘而删除；年谱可以翻到早年的主观理解。
- NPC 决策上下文包含自己的状态、观察过的联系人、有限记忆及合法行动，不传入全世界数据或他人内心。
- 生育经过九个月妊娠；夫妻的年龄、身体、亲缘、抚养意愿、财力和实际同住影响受孕。容量依据在世人口限制新受孕，历史人物不会阻断后代；已发生的妊娠继续结算。后代保留生父母与代数，孤儿由在世亲属接续照料；幼童随监护人迁居。
- 人物可以因衰老、疾病、伤重、意外、饥饿、灾害、难产死亡。疾病与伤势持续存在，可以求医；遗产真实转账，配偶、师承、监护、官职与组织主持随后接替。亡者保留档案，不继续获得新的主观经历。
- 临川县衙与门派、商会、义社同时存在。县令、捕头、主簿由实际 NPC 担任，六年任期与死亡可触发接替。工资/合作收益中的税款实际入库，俸银、育幼救济、公医治安和办案实际扣库；已败露侵吞可以报案，审理后按现有财产赔偿和缴罚。县衙不能自动获知未发现的秘密犯罪。
- 官员的合法候选行动包含支用有限公帑的公务；生育筹划、求医、报官同样可以由本地模型选取。月度家用的付款人及支出写入当月事件。
- 初始乡籍是明确的外生条件，登记以前的经历不编造；预演与正式游玩使用同一引擎。

`jianghu/engine.py` 结算世界，`social.py` 管时间机会、灰度行为与角色化解释，`ai.py` 管推理与提案，`store.py` 保存证据，`server.py` 提供本机接口；`static/` 是原生 HTML/CSS/JS 界面。

## 验证与已知边界

```powershell
python -m unittest discover -s tests -v
python scripts/validate.py --populations 100 500 1000 --months 120 --durable --output final_simulation.json
python scripts/validate.py --populations 100 --months 480 --output final_longrun.json
python scripts/compare_ai.py --samples 6
```

完整实验数据库保存在 `reports/`，数值结果见 `final_simulation.json`、`final_longrun.json`、`ai_comparison.json`；说明见 [VALIDATION.md](VALIDATION.md)。`--durable` 的时间包含逐月完整存档；不带此参数的批处理实验只在末尾完整存档。界面每月引擎耗时不包含存档与模型耗时。

本分支的同初始人口对照、真实模型覆盖与性能结果见 [RICHER_LIVES_VALIDATION.md](RICHER_LIVES_VALIDATION.md)。

上述为 v0.1 留存基线。世代、死因与县衙机制的当前验证见 [GENERATION_VALIDATION.md](GENERATION_VALIDATION.md)；原始数据在 `reports/generations-v2/`，可运行 `python scripts/validate_generations.py --seed 42 --years 120` 复查。

当前是可运行的机制原型：没有复杂战斗与物品系统，经济为工资/合作收入与生活开销的简化模型；五地迁移不模拟逐日路程；长期计划仍依靠有限目标和行动词表；关系会有重复行为。已有 AI 行动差异的证据，尚不能据此认定 AI 人格更可信，也没有完成长周期、全人口 AI 的质量评估。

人口可能增长或衰退，当前没有为了维持人数而凭空补人。生育率、医疗与老龄化参数尚未按历史人口数据校准。政府目前是单个县级机构，尚未模拟朝廷、战争、政权更替及完整官僚政治。

技术参考：[Ollama 结构化输出](https://docs.ollama.com/capabilities/structured-outputs)、[Ollama Chat API](https://docs.ollama.com/api/chat)、[llama.cpp 服务接口](https://github.com/ggml-org/llama.cpp/tree/master/tools/server)、[Qwen 官方 GGUF](https://huggingface.co/Qwen/Qwen3-4B-GGUF)。
